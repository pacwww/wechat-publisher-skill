# WeChat Publisher Skill

一套面向 Codex 的微信公众号 AI 内容生产工作流，把选题与素材转化为可发布文章。

## 能力

- 内容策划：受众、角度、标题与文章结构
- 文章生成：按观点、证据和案例生成初稿
- 公众号排版：优化标题层级、重点强调与移动端节奏
- 图片策划：封面方向、正文配图、比例及提示词
- 审核优化：检查事实、逻辑、表达、版权与发布规范
- 多格式输出：Markdown、HTML、微信可复制版本

## 安装

将 `wechat-publisher` 文件夹复制到 `~/.codex/skills/`，重新打开 Codex。

## 调用

> 使用 `$wechat-publisher`，把我的选题和素材制作成可发布的微信公众号文章。
