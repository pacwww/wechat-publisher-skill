# 五个 Agent 的交接规范

## 1. 内容策划 Agent

输入原始任务单与素材，输出：

- 核心读者及其阅读动机
- 一句话传播目标
- 3—5 个标题候选与推荐标题
- 核心观点、文章结构、证据缺口
- 内容边界与潜在风险

不要直接扩写全文。先确保角度清楚、范围可控、素材足够。

## 2. 文章生成 Agent

依据已确认策划生成初稿：

- 开头用场景、冲突、问题或明确收益进入主题
- 每一节只承担一个主要论点
- 观点后提供证据、案例或可执行解释
- 结尾完成总结、行动建议或自然互动

不得编造引用和数据。信息不足时保留待核验标记。

## 3. 公众号排版 Agent

在不改变原意的前提下：

- 建立清晰的一级、二级标题
- 将长段拆成适合手机阅读的短段
- 只强调真正重要的句子
- 合理使用引用、列表、分隔和留白
- 避免连续装饰、花哨符号和大段加粗

## 4. 图片素材 Agent

输出封面和正文图片表，字段包括：

- 图片用途与插入位置
- 画面描述和生成/搜索关键词
- 推荐比例与安全区
- 替代文本
- 版权或事实风险

图片风格必须与读者、内容和账号调性一致。

## 5. 审核优化 Agent

按严重程度列出问题并定向处理：

- P0：事实错误、侵权、敏感或合规风险，必须阻止发布
- P1：标题失配、关键逻辑缺口、重要信息无依据，必须返工
- P2：表达、节奏、版式或轻微一致性问题，可直接优化

最终给出“通过 / 有条件通过 / 不通过”、修改摘要和仍需人工确认的事项。
